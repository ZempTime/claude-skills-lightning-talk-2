My experience: it usually takes 3-5 conversations or completed tasks before you can turn that into a version of a skill.

Then it takes 3-5 versions before it starts getting really good and does everything right without you needing to think about it.

Part of this is because you need to do it enough to run into all the problems. But also, as the skill improves, new problems and things you didn't think about emerge. You learn.

One thing I'd suggest: if you start working on a skill, keep some release notes about what problems you tackled in each version. This is something I wish I would have done.
